# CleanUp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS menu bar app + window + widget that shows what is draining the battery or slowing the Mac and stops the idle culprits in one tap, never touching what's in use.

**Architecture:** All logic lives in a local Swift package `CleanUpCore`: system readers (libproc, IOKit, sysctl, a timeout-guarded command runner), one module per category that collects *facts*, a **pure judge** per category (facts → idle/in use + reasons, unit-tested against the 2026-11-01 incident), and an engine (scanner, selection, status, cleaner, drain monitor, snapshot store). The SwiftUI app (`CleanUp`) and the sandboxed WidgetKit extension (`CleanUpWidget`) are thin layers on top; the widget reads a JSON snapshot from the App Group and asks the app to clean via a Darwin notification.

**Tech Stack:** Swift 6.4, SwiftUI with Liquid Glass (`glassEffect`, `GlassEffectContainer`, `.glass`/`.glassProminent` button styles), WidgetKit, AppIntents, UserNotifications, ServiceManagement (`SMAppService`), FoundationModels, Swift Testing, XcodeGen (`/opt/homebrew/bin/xcodegen`), Xcode 27.1, macOS 27 SDK.

**Spec:** `docs/superpowers/specs/2026-11-02-cleanup-design.md` — read it before any task.

## Global Constraints

- Deployment target **macOS 26.0**. Bundle ID prefix `io.cleanup` (`io.cleanup.CleanUp`, `io.cleanup.CleanUp.Widget`).
- Main app **not sandboxed**; widget **sandboxed**. App Group: `$(DEVELOPMENT_TEAM).io.cleanup` (team-prefixed form). Team ID lives only in `Config/Team.xcconfig` (this Mac: `4896S8454F`); `Config/Team.xcconfig.example` is committed with a placeholder, `Team.xcconfig` is git-ignored.
- No network access, no analytics, no third-party dependencies.
- The idle verdict comes **only** from judges. Every judge combines idle conditions with **AND**; anything uncertain is `.inUse`.
- **Apps are never pre-ticked** and are never stopped by Quick select, the widget or the notification.
- Never list or stop: processes owned by root or other users, anything under `/System`, `/usr`, `/bin`, `/sbin`, `/Library/Apple`; Finder, Dock, WindowServer, CleanUp itself, the frontmost app.
- No external command or scan may block the main thread. Every external command goes through `CommandRunner` with a timeout (default 20 s).
- Refresh: every **5 s** while the window or popover is open, every **60 s** otherwise. External commands (`xcrun`, `docker`) at most every **30 s**.
- UI copy is short. Status moods exactly: `😌 All good`, `🟠 Busy`, `🔥 Draining fast`. Main button: `Clean up N idle · frees X cores`; when N is 0: `Nothing idle` (disabled). Toast: `Stopped N · Undo`. AI footer: `✨ Explained by Apple Intelligence, on this Mac`.
- Item icons are SF Symbols in colored rounded tiles; emoji only for the three moods.
- Category colors (my call): Simulators orange `#FF9F0A`, Containers blue `#0A84FF`, Dev servers purple `#BF5AF2`, Apps green `#30D158`, Browser tabs teal `#64D2FF`, Restart gray.
- License MIT. Tests use Swift Testing (`import Testing`, `@Test`, `#expect`).

## Review Focus

1. **External commands hang under load** (during the incident `simctl`/`ps` took 30 s+): the snapshot must still arrive with the other categories, and the slow category keeps its last result. → test `scannerSurvivesHangingCategory` in Task 7.
2. **Docker CLI present but daemon not running** (or no Docker at all): Containers category is simply absent, no error UI. → test `dockerDaemonDownYieldsNoItems` in Task 4.
3. **PID reused between scan and tap** (user taps Clean up minutes later): stopping must verify pid + start time and skip if they differ, never signalling a stranger. → test `stopSkipsReusedPID` in Task 5.
4. **A stop fails** (container won't stop, app cancels quit): toast reports `Couldn't stop 1`, item stays, freed cores count only successes. → test `cleanerCountsOnlySuccesses` in Task 7.
5. **No battery or plugged in** (Mac mini, charging): no minutes left, ring center shows cores busy, never `🔥`, warning never fires. → tests `desktopMacNeverDrainingFast` and `pluggedInNeverWarns` in Task 7.

### Task 2: System readers

**Files:**
- Create: `Sources/CleanUpCore/System/ProcessTable.swift`, `CPUSampler.swift`, `Sockets.swift`, `Battery.swift`, `SystemMemory.swift`, `CommandRunner.swift`
- Test: `Tests/CleanUpCoreTests/SystemTests.swift`

**Interfaces:**
- Produces:
  - `struct ProcessInfoRecord: Sendable, Hashable { let pid: Int32; let ppid: Int32; let pgid: Int32; let uid: uid_t; let name: String; let path: String; let arguments: [String]; let cwd: String?; let startTime: Date; let cpuTimeNanos: UInt64; let residentBytes: UInt64; var ref: ProcessRef }`
  - `enum ProcessTable { static func snapshot() -> [Int32: ProcessInfoRecord] }` — `proc_listallpids`, `proc_pidinfo(PROC_PIDTBSDINFO / PROC_PIDTASKINFO / PROC_PIDVNODEPATHINFO)`, `proc_pidpath`, args via `sysctl(KERN_PROCARGS2)`. Unreadable fields → empty/nil, never crash. Note `pti_total_user + pti_total_system` are in Mach absolute time units on Apple Silicon; convert with `mach_timebase_info`.
  - `actor CPUSampler { func sample(_ table: [Int32: ProcessInfoRecord], at: Date) -> [Int32: Double] }` — CPU % per pid since the previous sample (100 = one core); first call returns `[:]`.
  - `struct SocketInfo: Sendable, Hashable { enum State: Sendable { listen, established }; let pid: Int32; let state: State; let localPort: Int; let remotePort: Int? }` and `enum Sockets { static func tcp(for pids: [Int32]) -> [SocketInfo] }` — `PROC_PIDLISTFDS` + `proc_pidfdinfo(PROC_PIDFDSOCKETINFO)`, TCP only.
  - `enum Battery { static func read() -> BatteryReading? }` — IOKit `AppleSmartBattery`; nil when no battery. `drainWatts = abs(InstantAmperage as Int16-wrapped signed mA) × Voltage mV / 1e6` only when discharging; `minutesLeft` from `AvgTimeToEmpty` when < 65535 and on battery; `healthPercent = AppleRawMaxCapacity × 100 / DesignCapacity`.
  - `enum SystemMemory { static func swap() -> (used: UInt64, total: UInt64); static func uptime() -> TimeInterval; static func parseSwapUsage(_ s: String) -> (used: UInt64, total: UInt64)? }`
  - `struct CommandResult: Sendable { let status: Int32; let stdout: String; let stderr: String; let timedOut: Bool }` and `enum CommandRunner { static func run(_ launchPath: String, _ args: [String], timeout: Duration = .seconds(20)) async -> CommandResult }` — kills the child on timeout; resolves `docker`/`xcrun` through `/usr/bin/env`-style lookup of `/usr/local/bin`, `/opt/homebrew/bin`, `/usr/bin`, `~/.orbstack/bin`.

**Interfaces:**
